## 🖱️ How to Use vitrine on Your Website

Once you have the files, using vitrine is a copy-and-paste job. You add one script tag near the top of your web page, then you use the components wherever you want them to appear.

The script tag is the only setup step. After that, you place a component tag in your page where you want the content to show up — for example, a tag for a code viewer, a tag for a Markdown viewer, or a tag for a JSON tree. Each tag has a friendly name that describes what it does.

A typical workflow for a non-technical user looks like this:

- Open your web page file in any plain text editor, such as Notepad, which is already on every Windows computer.
- Paste the single script line into the page, near the top, exactly as it appears in the documentation.
- Paste the component tag where you want the content to appear.
- Save the file and refresh your browser. The content appears, styled and readable.

There is no build step, no package manager, and no terminal window required.

## ✨ What vitrine Can Display

vitrine is built around three kinds of content that people commonly need to show on a website. Each one gets its own dedicated component, designed to be clear and easy to read.

**Code blocks.** The code viewer shows programming code with syntax highlighting, so keywords, strings, and comments appear in different colors. This makes code far easier to read than plain black text. You can also turn on line numbers, which is helpful when you want to point at a specific line, and a search box so a visitor can jump straight to the part they need.

**Markdown text.** Markdown is a simple way of writing formatted text using plain characters. The Markdown viewer takes that plain text and renders it as headings, lists, links, bold words, and more. It also offers preview and source tabs, so your visitors can flip between the nicely formatted version and the raw text they could copy.

**JSON data.** JSON is a common format for structured data, often used by web services. On its own it is hard to read. The JSON viewer turns it into a collapsible tree, where you can expand and collapse sections with a click. This makes large data sets much easier to explore.

## 🎨 Making vitrine Match Your Site

Every part of vitrine can be restyled to match the look of your website. The components are themable with CSS variables, which are simple named settings for colors, spacing, and fonts. If you can change a color value in a style block, you can change how vitrine looks.

You can adjust background colors, text colors, accent colors for highlighted code, and the size of text. Because the components use Shadow DOM, your changes stay neatly organized and do not accidentally break other parts of your page — and your page's own styles do not leak in and break vitrine.

## 🔒 Safety and Privacy

vitrine is secure by default. All output is sanitized before it is displayed, which means harmful content hidden inside Markdown or data is cleaned out before it can reach a visitor's browser. The components are also CSP-friendly, so they work well on websites that follow strict security policies.

Nothing is sent to a third-party server to make the components work. They run entirely in the visitor's browser.

## 🧰 Built for Simplicity

It is also available as an ESM module if you prefer to load it that way, and it can be served from a CDN so you do not need to host files yourself.

No. You need to be able to copy a line of text and paste it into a file. That is the whole skill required.

Yes. Add the script line to each page where you want the components, or add it once in a shared header if your site has one.

Yes, once the files are saved on your computer, everything runs locally in the browser without an internet connection.
